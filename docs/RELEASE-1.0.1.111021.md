# Sky's Grass Slabs 1.0.1 for Minecraft 1.11.2

This is the first Minecraft 1.11.2 release of Sky's Grass Slabs. It includes
dirt, grass and lowered path slabs, thin turf, natural grass spreading and
grass slabs in suitable newly generated Overworld terrain.

Path slab side textures now follow the slab's lowered surface in the same way
as a vanilla path block. Top and bottom path slabs use the matching part of the
vanilla dirt path side texture.

Worlds saved with the Minecraft 1.10.2 release can be opened directly. Saved
slabs, turf, item stacks and world state retain their established identities.

Requires Minecraft 1.11.2, Forge 13.20.1.2588 or a compatible Forge 13.20.1
build, and Java 8.
