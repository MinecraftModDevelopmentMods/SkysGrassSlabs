# Sky's Grass Slabs 1.2.1 for NeoForge 26.2

Snowy slopes now start with snowy grass slabs when the surrounding terrain is covered.
The update also improves grass spreading around smaller building pieces, keeps saved
slabs safe from tree growth, and tidies crafting so the recipe book is easier to use.

Existing worlds, block IDs and settings are preserved. Terrain changes apply only
to newly generated chunks. Sky's Terrain Smoother remains optional.
