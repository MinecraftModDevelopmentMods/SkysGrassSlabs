# Sky's Grass Slabs 1.2.0.2601021

This version is for Minecraft 26.1.2 with Forge 64.0.9 and Java 25.

Open Config from the Mods list to change the settings, then restart Minecraft.
Two matching grass or dirt slabs can be crafted back into a full block.

Grass can spread between these slabs and grass pieces from Sky's Building Pieces.
If Sky's Terrain Smoother is installed, it handles new terrain for both mods.
The grass setting still controls whether it places grass pieces. Existing chunks stay as they are.
