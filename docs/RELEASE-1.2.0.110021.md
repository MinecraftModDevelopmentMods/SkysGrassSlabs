# SkysGrassSlabs 1.2.0.110021

Grass slabs now pick up snow from higher terraces and exposed cold ground.
Their snow caps change visually without changing saved orientations or drops.
The shared snow integration also supports the finer grass pieces in Building
Pieces and the Terrain Smoother BOP add-on.

Back up your world before updating. Install the main jar on the client and
server. Saved pieces retain their materials and orientations; new smoothing
applies only to newly generated chunks.
