# Sky's Grass Slabs 1.1.0 for Minecraft 1.18.2

Sky's Grass Slabs adds dirt, grass and lowered dirt path slabs, along with thin
turf. Grass spreads naturally between full blocks, slabs and turf, while
suitable slopes in newly generated Overworld terrain may use grass slabs to
soften one block steps.

This update adds an upgrade path for matching slabs and grass carpet from an
older grass slab mod. Supported blocks and items are recovered automatically
after the older mod is removed. An optional setting is available for modpacks
that want to convert the supported content while both mods are still present.

Slab orientation, waterlogging, item counts and custom item data are retained.
Decorative grass carpet is left in place when converting it to turf would make
it break from unsuitable support. Other shapes without a matching Sky block
remain outside the upgrade path.

Back up an existing world before removing or replacing any mod, and read the
complete Forge missing content list before confirming an upgrade.

Requires Minecraft 1.18.2, Forge 40.3.0 or a compatible Forge 40 build, and
Java 17.
