# Sky's Grass Slabs 1.1.0 for Minecraft 1.12.2

Adds optional integration with Sky's Building Pieces and Sky's Terrain Smoother.
Grass spreads between their matching dirt and grass pieces. Terrain Smoother
can own terrain generation without running a second grass slab pass.

The mod still works on its own. Existing blocks, orientation, configuration
defaults and saved migration progress are retained. Legacy recovery also keeps
custom item data and previously recorded chunk markers in mixed worlds.
Two matching dirt or grass slabs can be crafted back into their full block.

Requires Minecraft 1.12.2, Forge 14.23.5.2859 and Java 8. Back up existing
worlds before changing Minecraft versions or removing another mod.
