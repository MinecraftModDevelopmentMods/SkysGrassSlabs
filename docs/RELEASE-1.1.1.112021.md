# Sky's Grass Slabs 1.1.1 for Minecraft 1.12.2

You can now change the world-generation and legacy replacement settings from
**Mods → Sky's Grass Slabs → Config**. Each setting has help text. Save your
changes and restart Minecraft to apply them.

Grass slab smoothing now handles small plants that neighbouring decoration has
already placed on a slope. Trees, crops and occupied blocks stay protected,
and existing terrain is unchanged.

With Building Pieces installed, exposed grass beneath steps and corners stays
grassy. Full-cover slabs keep their usual dirt support. Grass Slabs still works
on its own, with the same blocks, recipes, configuration defaults and saved
migration progress.

Legacy recovery now explains its intentional registrations with one startup
notice. The historical IDs and recovery rules have not changed.

Requires Minecraft 1.12.2, Forge 14.23.5.2859 and Java 8. Back up your world before
updating mods or moving a world from an older Minecraft version.
