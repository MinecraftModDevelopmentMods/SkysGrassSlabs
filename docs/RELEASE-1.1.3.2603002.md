# Sky's Grass Slabs 1.1.3 for Minecraft 26.3

This update fixes crashes when starting the mod or loading a world with
newer NeoForge 26.3 builds. Earlier 26.3 builds still work.

You can keep your existing worlds and `skysgrassslabs-common.toml`. No
settings need to be changed, and blocks, recipes and terrain smoothing work
as before.

Requires Minecraft 26.3, NeoForge 26.3.0.1-beta or a compatible newer 26.3
build, and Java 25.
