# Sky's Grass Slabs 1.0.1.117011

This release brings Sky's Grass Slabs to Minecraft 1.17.1.

## Highlights

- Dirt, grass and lowered dirt path slabs with top and bottom placement.
- Natural grass spreading between full blocks, slabs and turf.
- Turf cutting, turf placement and sheep interaction.
- Biome colours, snowy slab caps and waterlogging.
- Grass slabs placed on suitable slopes in newly generated Overworld chunks.
- All 18 supported language variants.

## Updating a world

Back up the complete world before changing Minecraft or Forge versions. Keep
Sky's Grass Slabs installed during the first upgraded start so its blocks,
items and saved state can be carried forward. Worlds from Minecraft 1.10.2 to
1.12.2 receive the legacy block conversion when their chunks are opened;
newer supported worlds use their existing named block states.

See [Upgrading an older world](WORLD-UPGRADES.md) for the full checklist and
the limits of older mod content recovery.

## Requirements

Minecraft 1.17.1, Forge 37.1.1 or a compatible Forge 37 build, and Java 16.
