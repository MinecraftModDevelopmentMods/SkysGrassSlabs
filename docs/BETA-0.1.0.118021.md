# Beta 0.1.0.118021

This first Minecraft 1.18.2 beta established the permanent dirt, grass and
path slab identities and the saved world state used by later releases.

It added natural grass spreading and decay, biome colours, snow support,
plants and bonemeal, shovel flattening and helper recipes. Suitable one block
height changes in newly generated Overworld terrain could receive grass slabs.

The beta used Forge 40.3.0 and Java 17. It was superseded by the turf beta and
later stable releases.
