# Sky's Grass Slabs 1.0.1 for Minecraft 1.12.2

Sky's Grass Slabs brings dirt, grass and lowered path slabs, along with thin
turf, to Minecraft 1.12.2. Grass spreads naturally between full blocks, slabs
and turf, while suitable slopes in newly generated Overworld terrain may use
grass slabs to soften one block steps.

Both slab orientations, snowy edges, shovel paths, turf recipes and sheep
interaction are included. Path slab sides follow the lowered surface in the
same way as a vanilla path block. Fences and similar blocks treat turf like
vanilla carpet and do not connect to its sides. The turf recipe appears in the
recipe book after finding a grass block or grass slab.

Worlds saved with the Minecraft 1.10.2 or 1.11.2 releases can be upgraded
directly. Back up an existing world before changing its Minecraft version and
check the complete Forge missing content list before confirming an upgrade.

Requires Minecraft 1.12.2, Forge 14.23.5.2859 or a compatible Forge 14.23.5
build, and Java 8.
