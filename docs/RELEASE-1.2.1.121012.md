# Sky's Grass Slabs 1.2.1 for Minecraft 1.21.1

Slabs beside a higher snow-covered terrace now keep their snowy top.
They also recognise the snow pieces supplied by Sky's Building Pieces.
Removing the surrounding snow restores their green or dirt appearance.

This build uses Minecraft 1.21.1, NeoForge 21.1.247 and Java 21.
