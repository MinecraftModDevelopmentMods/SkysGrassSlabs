# Sky's Grass Slabs 1.2.0 for Minecraft 1.21.1

The Mods list now has a Config button for grass smoothing and recovery
settings. Changes take effect after a restart.

Two matching dirt or grass slabs can be crafted back into their original
block. With Sky's Building Pieces installed, grass can also spread between
the smaller grass pieces. Sky's Terrain Smoother can handle the shared
generation pass when installed.

Existing block and item IDs, saved data and settings carry forward. This
build requires Minecraft 1.21.1, NeoForge 21.1.247 and Java 21.
