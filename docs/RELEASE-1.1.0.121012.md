# Sky's Grass Slabs 1.1.0.121012

This release brings Sky's Grass Slabs to Minecraft 1.21.1 on NeoForge.

It includes dirt, grass and lowered dirt path slabs, plus turf. Grass spreads
between full blocks, slabs and turf, while suitable one block steps in newly
generated Overworld terrain can be smoothed with grass slabs.

## Highlights

- Dirt, grass and dirt path slabs with top and bottom placement.
- Waterlogging, biome tinting and snowy appearances.
- Turf cutting with a shovel that is returned unchanged.
- Natural grass spreading and sheep interaction.
- Deterministic smoothing for newly generated Overworld terrain.
- Support for upgrading selected content from older grass slab mods.
- Translated block names in 18 language variants.

This build requires Minecraft 1.21.1, NeoForge 21.1.247 or a compatible 21.1
build, and Java 21. Back up existing worlds before changing Minecraft, loader
or mod versions.
