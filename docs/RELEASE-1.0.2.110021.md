# Sky's Grass Slabs 1.0.2 for Minecraft 1.10.2

Improved recovery of legacy grass and dirt slabs in worlds that already contain
Sky slabs. Both slab orientations and saved item data are preserved, including
content in chunks visited by an earlier migration.

Gameplay, recipes, terrain generation and configuration defaults are unchanged.
Back up your world before removing any mod. Other legacy building pieces need
their own supported replacements.

Requires Minecraft 1.10.2, Forge 12.18.3.2511 and Java 8.
