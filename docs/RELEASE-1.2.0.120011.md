# Sky's Grass Slabs 1.2.0 for Minecraft 1.20.1

This update brings the shared grass rules and terrain integration to Minecraft
1.20.1. Grass Slabs still works on its own. When Sky's Terrain Smoother is
installed, it takes over terrain generation and Grass Slabs continues to
respect your grass generation setting.

- Grass steps and corners from Sky's Building Pieces can share spreading,
  decay and support rules with grass blocks and slabs.
- Two matching dirt or grass slabs can be crafted back into a full block.
- The configuration screen includes help for each setting. Save with Done,
  then restart Minecraft for the changes to take effect.
- Existing slab IDs, orientations, waterlogging, snowy states and migration
  data are retained. Existing terrain is left alone.

Requires Minecraft 1.20.1, Forge 47.4.10 and Java 17. Back up an existing world
before upgrading it, and test a copy before continuing with the original.
