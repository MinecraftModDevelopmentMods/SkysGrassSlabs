# Beta 0.2.0.118021

This Minecraft 1.18.2 beta fixed the dark texture on grass slab sides and
introduced the permanent turf block, item and recipe identities.

Turf is one pixel high and uses the surrounding biome colour. It spreads grass
while supported by dirt, can turn a dry dirt slab into a grass slab and can be
cut from a grass block or grass slab with a compatible shovel. The shovel is
returned unchanged and the matching dirt remains in the crafting grid.

All identities and saved world data from the first beta remained unchanged.
This beta was superseded by later stable releases.
