# Sky's Grass Slabs 1.2.1 for Minecraft 1.20.1

This update improves snowy grass slabs and keeps different crafting results on
their own recipe-book buttons. Slabs also check for entities before joining,
and smoothing protects saved terrain during nearby decoration.

Grass Slabs still works on its own. With Terrain Smoother installed, it shares
the updated grass and snow rules while respecting your generation setting.
Existing slab IDs, orientations, waterlogging and world data are preserved.

Requires Minecraft 1.20.1, NeoForge 47.1.106 and Java 17. Back up existing worlds
before updating. Worlds using Forge Mineralogy should remain on Forge.
