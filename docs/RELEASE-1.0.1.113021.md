# Sky's Grass Slabs 1.0.1 for Minecraft 1.13.2

Sky's Grass Slabs adds dirt, grass and lowered path slabs, along with thin
turf, to Minecraft 1.13.2. Grass spreads naturally between full blocks, slabs
and turf, while suitable slopes in newly generated Overworld terrain may use
grass slabs to soften one block steps.

This release includes both slab orientations, waterlogging, snowy caps,
shovel paths, turf recipes and sheep interaction. Matching slabs combine into
their vanilla full blocks, and the turf recipe returns the shovel unchanged.
The block names are available in 18 supported language variants.

Worlds saved with the Minecraft 1.10.2, 1.11.2 or 1.12.2 releases can be
upgraded directly. Sky blocks, items, orientations and saved world state are
preserved across Minecraft 1.13's changed world format. Back up an existing
world before changing its Minecraft version and read the complete Forge
missing content list before confirming an upgrade.

Requires Minecraft 1.13.2, Forge 25.0.223 or a compatible Forge 25 build, and
Java 8.
