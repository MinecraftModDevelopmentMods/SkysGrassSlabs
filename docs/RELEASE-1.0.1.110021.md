# Sky's Grass Slabs 1.0.1 for Minecraft 1.10.2

This maintenance release corrects the side texture alignment on both top and
bottom path slabs. The dirt path pattern now lines up with the slab's lowered
surface in the same way as a vanilla path block.

Gameplay, recipes, world generation, configuration and saved block identities
are unchanged.

Requires Minecraft 1.10.2, Forge 12.18.3.2511 or a compatible Forge 12.18.3
build, and Java 8.
