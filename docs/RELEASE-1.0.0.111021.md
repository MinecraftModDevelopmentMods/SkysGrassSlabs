# Sky's Grass Slabs 1.0.0 for Minecraft 1.11.2

This release brings dirt, grass and lowered path slabs, turf and smoother
Overworld terrain to Minecraft 1.11.2.

## Features

- Place dirt, grass and path slabs in either half of a block.
- Combine two matching slabs into the corresponding vanilla block.
- Let grass spread naturally between full blocks, slabs and turf.
- Use a shovel on dirt or grass slabs to make lowered path slabs.
- Cut turf from grass without using up the shovel.
- Let sheep eat turf and regrow their wool.
- Add grass slabs to suitable one block height changes in newly generated
  Overworld terrain.
- Display complete snow caps on grass and dirt slabs in snowy areas.
- Use translated block names in 18 supported language variants.

Worlds saved with the Minecraft 1.10.2 release can be opened directly. The
four saved block identities, slab orientation, item stacks and world state are
retained during the upgrade and on later reloads.

This version requires Minecraft 1.11.2 and Forge 13.20.1.2588 or a compatible
Forge 13.20.1 build. Back up an important world before changing its Minecraft
version.
